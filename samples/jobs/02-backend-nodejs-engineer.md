# Job Description: Backend Serverless Node.js Engineer

- **Job ID:** `job-be-02`
- **Department:** Cloud Platform & Backend
- **Company:** TechCorp Vietnam
- **Location:** Ho Chi Minh City / Remote
- **Salary Range:** $1,500 - $2,500 / month
- **Experience Level:** 2 - 5 years

## 1. Role Overview
We are seeking a Backend Serverless Engineer experienced in Node.js and TypeScript to design, build, and maintain scalable serverless microservices on AWS.

## 2. Key Responsibilities
- Architect and develop serverless RESTful APIs using AWS Lambda and Amazon API Gateway.
- Design high-performance, single-table NoSQL data models using Amazon DynamoDB.
- Build asynchronous, event-driven pipelines using Amazon SQS, SNS, and S3 Event Notifications.
- Integrate third-party AI services, specifically Amazon Bedrock (LLM) and Amazon Textract (OCR).
- Write comprehensive unit and integration tests using Vitest or Jest.
- Implement security best practices (IAM least privilege, data encryption at rest and in transit).

## 3. Required Qualifications & Skills
- **Core Technical Skills (Weight: 40%):**
  - Strong proficiency in Node.js (v18+) and TypeScript.
  - Hands-on experience with AWS core serverless services: Lambda, API Gateway, DynamoDB, S3, SQS.
  - Familiarity with AWS SDK for JavaScript v3 (`@aws-sdk/client-*`).
  - Solid understanding of RESTful API design and asynchronous event-driven architecture.
- **Experience & Practical Track Record (Weight: 30%):**
  - 2+ years of professional backend development experience in production environments.
  - Experience designing NoSQL data access patterns (DynamoDB Single-Table Design is a strong plus).
  - Familiarity with Infrastructure as Code (AWS CDK or Terraform).
- **Education & Foundational Knowledge (Weight: 15%):**
  - Bachelor's degree in Information Technology, Computer Science, or equivalent practical experience.
  - AWS Certified Developer or Solutions Architect Associate is a valued advantage.
- **Soft Skills & Presentation (Weight: 15%):**
  - Strong analytical and debugging skills.
  - Clear documentation habits and proactive teamwork mindset.
