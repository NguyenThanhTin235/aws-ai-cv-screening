# Agent Guidelines & Rules

## 1. Nghiên cứu giải pháp mã nguồn mở trước khi triển khai (Research Open Source First)

> **"Đối với những chức năng chưa quen thuộc, đừng viết từ con số 0, hãy tìm kiếm các dự án mã nguồn mở trên GitHub để so sánh ý tưởng trước khi bắt tay vào làm."**

### Quy trình thực hiện:
1. **Nhận diện**: Khi gặp chức năng mới lạ, kiến trúc phức tạp hoặc thư viện chưa từng làm việc trong codebase, tuyệt đối **không tự viết từ đầu (reinvent the wheel)**.
2. **Khảo sát GitHub / Open-source**: Chủ động tìm kiếm các repository hoặc reference implementation tiêu biểu trên GitHub liên quan đến tính năng đó.
3. **So sánh & Đánh giá ý tưởng**: So sánh các phương án tiếp cận (ưu/nhược điểm, best practices, độ tương thích với stack của dự án).
4. **Báo cáo & Triển khai**: Tóm tắt phương án đã chọn và giải thích lý do trước khi bắt tay vào triển khai code.
