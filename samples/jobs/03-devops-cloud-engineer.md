# Job Description: DevOps & Cloud Infrastructure Engineer

- **Job ID:** `job-ops-03`
- **Department:** Cloud Infrastructure & SRE
- **Company:** TechCorp Vietnam
- **Location:** Ho Chi Minh City (Hybrid)
- **Salary Range:** $1,600 - $2,600 / month
- **Experience Level:** 2 - 5 years

## 1. Role Overview
We are looking for a DevOps & Cloud Infrastructure Engineer to manage our Infrastructure as Code (IaC), CI/CD pipelines, and cloud observability on AWS.

## 2. Key Responsibilities
- Define, deploy, and manage multi-environment AWS infrastructure using AWS CDK (TypeScript).
- Implement robust CI/CD pipelines with GitHub Actions for automated linting, testing, and zero-downtime deployment.
- Configure cloud monitoring, alarms, metrics, and dashboards using Amazon CloudWatch.
- Enforce cloud security policies, IAM least privilege, S3 bucket encryption, and audit logging.
- Monitor cloud costs, implement automated cost alerts with AWS Budgets, and optimize resource utilization.

## 3. Required Qualifications & Skills
- **Core Technical Skills (Weight: 40%):**
  - Strong experience with AWS Core services (IAM, VPC, S3, CloudFront, CloudWatch, Lambda).
  - Proficiency in Infrastructure as Code using AWS CDK (TypeScript preferred) or Terraform.
  - Strong scripting and automation skills (Bash, TypeScript/Node.js, or Python).
  - Solid knowledge of CI/CD pipeline automation (GitHub Actions, GitLab CI).
- **Experience & Practical Track Record (Weight: 30%):**
  - 2+ years of experience working in DevOps, Cloud Engineering, or SysAdmin roles.
  - Hands-on experience troubleshooting production incidents and configuring alert thresholds.
  - Familiarity with Serverless architectures and event-driven patterns.
- **Education & Foundational Knowledge (Weight: 15%):**
  - Bachelor's degree in Computer Science, Computer Engineering, or related discipline.
  - AWS Certifications (Solutions Architect Associate / SysOps Administrator) strongly preferred.
- **Soft Skills & Presentation (Weight: 15%):**
  - Proactive attitude towards automation and reliability.
  - Strong written and verbal technical documentation skills.
