# Job Description: Senior Frontend React Engineer

- **Job ID:** `job-fe-01`
- **Department:** Engineering
- **Company:** TechCorp Vietnam
- **Location:** Ho Chi Minh City (Hybrid)
- **Salary Range:** $1,200 - $2,000 / month
- **Experience Level:** 2 - 4 years

## 1. Role Overview
We are looking for a talented Frontend React Engineer to build high-performance, accessible, and responsive web applications for our cloud-based recruitment platform.

## 2. Key Responsibilities
- Develop responsive web user interfaces using modern React (Hooks, Context, Functional Components).
- Write modular, reusable, and type-safe components with TypeScript.
- Implement sleek, modern user interfaces using Vanilla CSS / CSS Modules with Design Tokens (variables), supporting dark/light themes and micro-animations.
- Integrate RESTful APIs and handle asynchronous states, error boundaries, and optimistic updates.
- Optimize frontend bundle size and web performance metrics (Core Web Vitals).

## 3. Required Qualifications & Skills
- **Core Technical Skills (Weight: 40%):**
  - Strong proficiency in JavaScript (ES6+) and TypeScript.
  - 2+ years of hands-on production experience with React.js.
  - Deep understanding of modern CSS (Flexbox, Grid, CSS Variables, Transitions).
  - Experience integrating with REST APIs and handling token-based authentication (JWT).
- **Experience & Practical Track Record (Weight: 30%):**
  - Proven track record of shipping production-ready web applications.
  - Experience with Git version control and modern build tools (Vite, Webpack).
  - Familiarity with state management patterns and client caching.
- **Education & Foundational Knowledge (Weight: 15%):**
  - Bachelor's degree in Computer Science, Software Engineering, or related technical field.
- **Soft Skills & Presentation (Weight: 15%):**
  - Clean code principles, clear communication, and solid problem-solving skills.
  - Ability to work effectively in an Agile/Scrum environment.
